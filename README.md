# Task 10 - AI vs ML vs Deep Learning

## AI & ML Internship

### Objective

The objective of this task is to understand the differences between Artificial Intelligence (AI), Machine Learning (ML), and Deep Learning (DL), along with their real-world applications.

## Description

This project presents a simple comparison of AI, ML, and Deep Learning using Python. It explains their definitions, working methods, and real-world examples to understand how they are different and related.

## Tools and Technologies

* Python
* Jupyter Notebook
* Pandas
* Markdown

## Comparison

| Concept                      | Definition                                                                  | Working                                            | Real-World Example   |
| ---------------------------- | --------------------------------------------------------------------------- | -------------------------------------------------- | -------------------- |
| Artificial Intelligence (AI) | Enables machines to perform tasks that normally require human intelligence. | Uses rules, logic, search, or learning techniques. | Virtual assistants   |
| Machine Learning (ML)        | Enables machines to learn patterns from data and make predictions.          | Uses algorithms to learn from data.                | Email spam detection |
| Deep Learning (DL)           | Uses multi-layered neural networks to learn complex patterns.               | Learns through multiple neural network layers.     | Facial recognition   |

## Relationship Between AI, ML, and Deep Learning

Artificial Intelligence is the broader field of creating intelligent systems. Machine Learning is a subset of AI that allows systems to learn from data. Deep Learning is a subset of Machine Learning that uses multi-layered neural networks to identify complex patterns.

**AI ⊃ ML ⊃ DL**
